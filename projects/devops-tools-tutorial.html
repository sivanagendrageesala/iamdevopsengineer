🛠️ DevOps Tools - One by One

Master essential DevOps tools with examples and use cases

🐙
Git
Version Control System - Track code changes
What is Git?
Tracks every change made to your code
Allows multiple developers to work together
Go back to any previous version anytime
Prevents code conflicts and loss
Write Code
→
Commit
→
Push
→
Remote
$ git add .
$ git commit -m "Added new feature"
$ git push origin main
# Your code is now in remote repository
🚀
Jenkins
CI/CD Automation Server - Automate testing and deployment
What is Jenkins?
Automatically runs tests when code is pushed
Catches bugs before they reach production
Automatically deploys code if tests pass
Saves time and reduces manual errors
Code Push
→
Trigger
→
Test
→
Deploy
# Jenkins pipeline automatically:
1. Pulls code from Git
2. Builds application
3. Runs unit tests
4. Deploys to server
📦
Docker
Containerization - Package apps with all dependencies
What is Docker?
Packages app + all dependencies in a container
"Works on my machine" problem solved
Containers run same way everywhere
Lightweight and fast compared to VMs
Code
→
Dockerfile
→
Image
→
Container
$ docker build -t myapp:1.0 .
$ docker run -p 8080:8080 myapp:1.0
# App running in container on port 8080
⚙️
Kubernetes (K8s)
Container Orchestration - Manage thousands of containers
What is Kubernetes?
Automatically scales containers up/down
Handles container deployment and updates
Self-healing - restarts failed containers
Load balancing across multiple containers
Docker Image
→
Deploy
→
Scale
→
Manage
$ kubectl apply -f deployment.yaml
$ kubectl scale deployment myapp --replicas=5
# K8s creates 5 copies of your app
🏗️
Terraform
Infrastructure as Code - Manage cloud resources with code
What is Terraform?
Define infrastructure in code files
Create servers, databases, networks automatically
Version control for infrastructure
Works with AWS, Azure, GCP, etc.
Write Code
→
Plan
→
Apply
→
Infra Live
resource "aws_instance" "example" {
ami = "ami-0c55b159cbfafe1f0"
instance_type = "t2.micro"
}
$ terraform apply
🤖
Ansible
Configuration Management - Automate server setup
What is Ansible?
Configure servers without writing scripts
Install packages, manage files, restart services
Same configuration across all servers
Simple YAML syntax, easy to learn
Write Playbook
→
Run
→
Configure
→
Done
- name: Install and start Apache
hosts: webservers
tasks:
- yum: name=httpd state=present
$ ansible-playbook playbook.yml

What is Prometheus?

Query metrics for dashboards and reports
