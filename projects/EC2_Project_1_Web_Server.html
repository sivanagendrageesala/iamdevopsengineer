🚀 EC2 Project 1: Deploy a Web Server

AWS EC2 Fundamentals → Step-by-Step Project

Project Overview

In this project, you'll launch an EC2 instance, configure it as a web server, and make it accessible from the internet. This covers the fundamental workflow of working with EC2.

Duration: 30-45 minutes | Difficulty: Beginner | Cost: ~$0.01 (t2.micro free tier eligible)

What You'll Learn:

  • Launch an EC2 instance from the AWS Console
  • Create and manage security groups
  • Connect to your instance via SSH
  • Install and configure a web server (Nginx)
  • Access your web server from a browser

Prerequisites

  • AWS Account with free tier access
  • SSH client installed (built-in on macOS/Linux, PuTTY or Windows Terminal for Windows)
  • Basic understanding of Linux commands

Step 1: Launch an EC2 Instance

1

Open EC2 Dashboard

Go to AWS Console → Services → EC2 → Instances → Launch Instances

2

Choose an AMI (Amazon Machine Image)

Select Amazon Linux 2 - it's free tier eligible and great for beginners

Details: Amazon Linux 2 is optimized for EC2, includes AWS tools, and is free tier eligible.

3

Choose Instance Type

Select t2.micro - this is free tier eligible

Instance Type vCPU Memory Use Case
t2.micro 1 1 GB Low-traffic apps, testing, learning
t2.small 1 2 GB Small web applications
4

Configure Instance Details

  • Number of instances: 1
  • Network: Default VPC
  • Subnet: Default subnet
  • Auto-assign IPv4: Enable
  • Click Next
5

Add Storage

  • Root volume size: 8 GB (free tier allows up to 30 GB)
  • Volume type: gp2 or gp3
  • Delete on termination: Yes
  • Click Next
6

Add Tags

Tags help you organize and identify your instances.

Key Value
Name MyWebServer
Environment Learning
Project EC2Fundamentals

Click Next

7

Configure Security Group (Critical Step!)

This controls who can access your instance

  • Name: WebServerSecurityGroup
  • Description: Allow HTTP and HTTPS traffic
  • Add these inbound rules:
Type Protocol Port Range Source Purpose
SSH TCP 22 0.0.0.0/0 (or your IP) Admin access via SSH
HTTP TCP 80 0.0.0.0/0 Web traffic
HTTPS TCP 443 0.0.0.0/0 Secure web traffic
⚠️ Security Note: For production, restrict SSH to your IP address (not 0.0.0.0/0)
8

Review and Launch

  • Review all settings
  • Click Launch
9

Create/Select Key Pair

  • Create a new key pair or select existing
  • Key pair name: MyEC2KeyPair
  • Download the .pem file (save it somewhere safe)
  • Click Launch Instances
✅ Your instance is now launching! It will be in "running" state in 30-60 seconds.

Step 2: Connect to Your Instance

1

Wait for Instance to Run

  • Go to EC2 → Instances
  • Wait until your instance shows "running" status
  • Note down the Public IPv4 address (e.g., 54.123.45.67)
2

Set Permissions on Key File (macOS/Linux)

chmod 400 ~/Downloads/MyEC2KeyPair.pem

Why? SSH requires the key file to have restricted permissions for security.

3

SSH into Your Instance

Replace PUBLIC_IP with your actual public IPv4 address

ssh -i ~/Downloads/MyEC2KeyPair.pem ec2-user@PUBLIC_IP

Example:

ssh -i ~/Downloads/MyEC2KeyPair.pem ec2-user@54.123.45.67

Type yes when prompted to accept the host key.

✅ You're now connected to your EC2 instance!
4

Verify Connection

whoami
uname -a
df -h

These commands verify you're logged in and show system info.

Step 3: Install and Configure Nginx Web Server

1

Update System Packages

sudo yum update -y

Why? Ensures you have the latest security patches and software versions.

2

Install Nginx

sudo yum install -y nginx

This installs Nginx, a lightweight and efficient web server.

3

Start Nginx Service

sudo systemctl start nginx
sudo systemctl enable nginx

start: Begins the service now
enable: Ensures it starts automatically after reboot

4

Verify Nginx is Running

sudo systemctl status nginx

Should show active (running)

5

Create a Custom Web Page

sudo bash -c 'cat > /usr/share/nginx/html/index.html << EOF
<!DOCTYPE html>
<html>
<head>
    <title>My EC2 Web Server</title>
    <style>
        body { font-family: Arial; margin: 50px; background: #f0f0f0; }
        h1 { color: #ff9900; }
    </style>
</head>
<body>
    <h1>🎉 Welcome to My EC2 Web Server!</h1>
    <p>This page is being served from an EC2 instance.</p>
    <p>Instance ID: $(ec2-metadata --instance-id | cut -d " " -f 2)</p>
    <p>Availability Zone: $(ec2-metadata --availability-zone | cut -d " " -f 2)</p>
</body>
</html>
EOF'
6

Access Your Web Server

  • Open your browser
  • Navigate to: http://YOUR_PUBLIC_IP
  • You should see your custom web page!
✅ Your web server is live on the internet!

Step 4: Monitor and Manage

View Nginx Logs

sudo tail -f /var/log/nginx/access.log

Shows incoming web requests in real-time.

Check Instance Resource Usage

free -h          # Memory usage
df -h             # Disk usage
top               # CPU and process info (press q to exit)

Useful AWS CLI Commands (from your local machine)

# List running instances
aws ec2 describe-instances --filters "Name=instance-state-name,Values=running"

# Get instance details
aws ec2 describe-instances --instance-ids i-0123456789abcdef0

# Reboot instance
aws ec2 reboot-instances --instance-ids i-0123456789abcdef0

# Stop instance (keeps data, charges storage)
aws ec2 stop-instances --instance-ids i-0123456789abcdef0

# Terminate instance (deletes everything, no charges)
aws ec2 terminate-instances --instance-ids i-0123456789abcdef0

Step 5: Cleanup (Important for Cost!)

When you're done learning, terminate your instance to avoid charges.

💰 Cost Impact:
  • t2.micro running 24/7: ~$7/month (outside free tier)
  • Stopping the instance: Still pays for storage (~$1/month)
  • Terminating the instance: No charges (except storage if retained)

Terminate Your Instance

  1. Go to EC2 → Instances
  2. Right-click your instance → Instance State → Terminate
  3. Confirm termination
⚠️ Warning: Terminating deletes the instance and all its data. Make sure you've saved anything important.

Troubleshooting

Problem Solution
Can't SSH to instance Check security group allows port 22, key file has 400 permissions, correct IP address used
Web page not accessible Verify security group allows port 80, Nginx is running (sudo systemctl status nginx)
Instance stuck in "pending" Wait 2-3 minutes, or check for errors in launch details
Permission denied with key file Run: chmod 400 MyEC2KeyPair.pem

Key Concepts Summary

  • AMI: Template that defines the OS and software
  • Instance Type: Virtual hardware specs (vCPU, RAM)
  • Key Pair: Authentication credentials for SSH access
  • Security Group: Virtual firewall controlling inbound/outbound traffic
  • Public IP: Internet-accessible address (changes on stop/start)
  • Elastic IP: Static IP that persists across stop/start (paid feature)
