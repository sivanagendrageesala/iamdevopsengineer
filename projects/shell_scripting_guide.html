1. Your First Script

Creating a Script

A shell script is a text file with commands that bash executes line by line.

Example: hello.sh

#!/bin/bash
echo "Hello, World!"
Rules:
  • #!/bin/bash must be the FIRST line (shebang)
  • Tells the system to use bash to run this file
  • Each new line = one command

Running a Script

chmod +x hello.sh        # Make it executable
./hello.sh                # Run it

Output:
Hello, World!

2. Variables & Input

Creating Variables

Syntax: variablename=value

Important: NO SPACES around =
Example:

name="Alice"        # Create a variable
echo "Hello, $name"   # Use $ to get the value

Output:
Hello, Alice

Using Arguments ($1, $2, etc.)

What are arguments?
Values you pass when running the script

$1 = First argument
$2 = Second argument
$@ = All arguments
Example: greet.sh

#!/bin/bash
name=$1
age=$2
echo "Hello $name, you are $age years old"

Running it:
./greet.sh Bob 25

Output:
Hello Bob, you are 25 years old

3. Syntax Rules & Formatting

Spaces Around = (Assignment vs Comparison)

✅ CORRECT

name=bob               # NO spaces (assigning)
if [ $name = "bob" ]; then   # SPACES around = (comparing)
❌ WRONG

name = bob               # Spaces break assignment
if [ $name="bob" ]; then         # No spaces breaks comparison
Rule:
  • Assigning a variable: name=value (NO spaces)
  • Comparing in if: [ $name = "value" ] (SPACES required)

The [ ] Bracket

Always use spaces inside brackets:

[ condition ]   ✅ CORRECT
[condition]          ❌ WRONG

The $ Symbol

Use $ to GET a value from a variable

name="Alice"            # Store "Alice"
echo $name               # Prints: Alice
echo name                 # Prints: name (the word)

Semicolons

Use ; to end a command on the same line:

if [ $x = 5 ]; then
The ; separates the condition from then

4. Conditionals (if/else)

Basic Structure

Example:

#!/bin/bash
age=$1

if [ $age -ge 18 ]; then
    echo "You are an adult"
else
    echo "You are a minor"
fi

Comparison Operators

Operator Meaning Example
-eq Equal [ $x -eq 5 ]
-ne Not equal [ $x -ne 5 ]
-gt Greater than [ $x -gt 5 ]
-ge Greater or equal [ $x -ge 5 ]
-lt Less than [ $x -lt 5 ]
-le Less or equal [ $x -le 5 ]
= String equal [ $name = "Bob" ]
!= String not equal [ $name != "Bob" ]

File Checks

Check Meaning
[ -f file ] File exists
[ -d dir ] Directory exists
[ -z string ] String is empty
[ -n string ] String is not empty

Combining Conditions

AND:
if [ $age -ge 18 ] && [ $country = "USA" ]; then

OR:
if [ $age -lt 18 ] || [ $age -gt 65 ]; then

5. For Loops

Basic For Loop

Example:

#!/bin/bash
for i in 1 2 3 4 5; do
    echo "Number: $i"
done

Output:
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5

For Loop with Range

Syntax: for i in {START..END}; do

Bash automatically generates all numbers from START to END
Example: Count 1 to 10

#!/bin/bash
for i in {1..10}; do
    echo "Count: $i"
done
Example: Count backward 20 to 10

#!/bin/bash
for i in {20..10}; do
    echo "Number: $i"
done

Bash automatically counts backward!

For Loop with Variable Range

Problem: {$n..10} does NOT work
Variables don't expand inside {..}

Solution: Use seq command with $()
Example:

#!/bin/bash
n=$1
for i in $(seq 1 $n); do
    echo "Number: $i"
done

./script.sh 5
Output: 1, 2, 3, 4, 5

Practical Example: Print Stars

Print 5 stars on one line: *****

#!/bin/bash
no=$1
for i in $(seq 1 $no); do
    echo -n "*"
done
echo ""    # New line after

./stars.sh 5
Output: *****
Key points:
  • echo -n prints without a newline
  • Without -n, each star would be on its own line
  • echo "" at the end moves to the next line

6. While Loops

Basic While Loop

Example: Count down from 5 to 1

#!/bin/bash
count=5
while [ $count -gt 0 ]; do
    echo $count
    count=$((count - 1))
done
echo "Blast off!"

Output:
5
4
3
2
1
Blast off!

How While Works

Syntax: while [ condition ]; do

1. Check condition
2. If TRUE, run commands inside
3. Go back to step 1
4. If FALSE, skip to after done

Counting Up with While

Example: Count 1 to 5

#!/bin/bash
count=1
no=$1
while [ $count -le $no ]; do
    echo $count
    count=$((count + 1))
done

./countup.sh 5
Output:
1
2
3
4
5
Key points:
  • -le means "less than or equal"
  • count=$((count + 1)) adds 1 each time
  • Without incrementing, the loop runs forever!

7. Common Brackets & Syntax

Different Types of Brackets

Syntax Purpose Example
[ ] Test/condition if [ $x -gt 5 ]; then
$( ) Run command, capture output for i in $(seq 1 5); do
$(( )) Do math count=$((count + 1))
{ } Generate range for i in {1..10}; do

Understanding $( ) - Command Substitution

$( ) means:
"Run the command inside and use its output"
Example:

seq 1 5                  # This command outputs: 1 2 3 4 5
$(seq 1 5)               # Captures that output

for i in $(seq 1 5); do       # Same as: for i in 1 2 3 4 5; do

Understanding $(( )) - Arithmetic

$(( )) means:
"Do math inside these parentheses"
Examples:

count=$((count + 1))       # Add 1
total=$((5 + 3))             # total = 8
result=$((count - 1))       # Subtract 1
product=$((10 * 5))         # Multiply
divided=$((20 / 4))         # Divide

When Spaces Matter

Variable assignment (NO spaces):
name=bob    ✅
name = bob    ❌

Conditionals (spaces required):
[ $x = 5 ]    ✅
[$x=5]    ❌

Math (spaces optional but clearer):
$((x + 1))    ✅
$((x+1))    ✅ (also works)

8. Quick Reference

Template for Common Scripts

Simple Script Template:

#!/bin/bash

# Get arguments
variable=$1

# Check something
if [ condition ]; then
    echo "Do something"
else
    echo "Do something else"
fi

# Loop
for i in $(seq 1 10); do
    echo $i
done

Cheat Sheet

Task Syntax
Create variable name=value
Use variable echo $name
Get first argument $1
Print text echo "text"
Print without newline echo -n "text"
If-else if [ condition ]; then ... else ... fi
For loop for i in {1..10}; do ... done
While loop while [ condition ]; do ... done
Add 1 count=$((count + 1))
Check if greater than [ $x -gt 5 ]

Common Mistakes & Fixes

Mistake Fix Why
name = value name=value No spaces in assignment
if [$x=5] if [ $x = 5 ] Spaces required in [ ]
count=$(count+1) count=$((count + 1)) Double (( )) for math
for i in {$n..10} for i in $(seq 1 $n) Variables don't expand in { }
echo $name (without "$") echo $name Use $ to get variable value
