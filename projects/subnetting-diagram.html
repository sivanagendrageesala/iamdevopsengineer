🔍 How IP Addresses Are Split
Example: 192.168.1.50/24
192.168.1
Network (24 bits)
.50
Host (8 bits)

✓ The first 3 octets (192.168.1) identify the FLOOR
✓ The last octet (.50) identifies YOUR DEVICE on that floor

💡 Key Takeaways

✓ Main Building = 192.168.0.0/16

• Can have many floors (subnets)

• Each floor = 192.168.X.0/24

• Each device on a floor gets a unique IP (192.168.X.1 to 192.168.X.254)

• Devices on Floor 1 talk FAST to each other (same subnet)

• Devices talking to other floors need a ROUTER (gateway) 🚪
