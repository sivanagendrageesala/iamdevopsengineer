☁️ AWS Services - Visual Guide

Comprehensive Visual Explanations of AWS Services

🖥️

EC2

Elastic Compute Cloud

What it does

Rents virtual computers (instances) that you can configure and control. Like having your own personal server in the cloud.

Key Features

  • Choose processor power (t2.micro → m5.24xlarge)
  • Choose memory and storage
  • Choose operating system (Linux, Windows)
  • Pay per hour/second of usage
  • Scale up or down instantly
Use Case: Hosting web servers, running applications, batch processing jobs, development environments
⚡

Lambda

Serverless Compute

What it does

Run code without managing servers. You upload code and it runs automatically when triggered.

Key Features

  • No server management needed
  • Pay only for execution time
  • Automatic scaling
  • Triggered by events
  • Support for Python, Node.js, Java, Go
Use Case: Image processing, real-time file processing, automated backups, API responses
📦

ECS

Elastic Container Service

What it does

Run Docker containers at scale. Manage and orchestrate containerized applications.

Key Features

  • Run Docker containers
  • Automatic scaling based on load
  • Load balancing
  • Health monitoring
  • Integration with other AWS services
Use Case: Microservices architecture, containerized applications, continuous deployment
🎛️

Elastic Beanstalk

Platform as a Service

What it does

Deploy and manage applications without thinking about infrastructure. A simplified way to run apps.

Key Features

  • One-click deployment
  • Automatic scaling
  • Built-in monitoring
  • Supports multiple languages
  • No infrastructure management
Use Case: Deploying web applications quickly, prototype development, small-to-medium apps
🪣

S3

Simple Storage Service

What it does

Store any amount of data (files, images, videos, backups) and retrieve it from anywhere in the world.

Key Features

  • Unlimited storage capacity
  • Highly available and durable
  • Pay per GB stored
  • Version control
  • Access control and encryption
Use Case: Website static files, backup storage, big data analytics, archive storage
💾

EBS

Elastic Block Store

What it does

Block storage volumes for EC2 instances. Think of it as hard drives for your virtual computers.

Key Features

  • Attach to EC2 instances
  • Snapshots and backups
  • Encryption
  • High performance
  • Pay per GB per month
Use Case: Databases, file systems, persistent storage for applications
📁

EFS

Elastic File System

What it does

Shared file storage that multiple EC2 instances can access simultaneously. Like a shared network drive.

Key Features

  • Shared across instances
  • Automatic scaling
  • High availability
  • NFS protocol support
  • Pay per GB used
Use Case: Shared code repositories, shared media files, collaborative work
❄️

Glacier

Cold Storage Archive

What it does

Ultra-cheap long-term storage for data you rarely access. Slower retrieval but much cheaper.

Key Features

  • Very low cost (1¢ per GB/month)
  • 3-5 hour retrieval time
  • 99.999% durability
  • Compliance and archival
  • Vault Lock for immutability
Use Case: Compliance backups, long-term archives, disaster recovery
🗄️

RDS

Relational Database Service

What it does

Managed relational databases. AWS handles backups, updates, and maintenance for you.

Key Features

  • Supports MySQL, PostgreSQL, Oracle, SQL Server
  • Automated backups
  • Multi-AZ deployment for high availability
  • Read replicas for scaling reads
  • Automatic patching
Use Case: Web applications, ERP systems, business applications with structured data
⚙️

DynamoDB

NoSQL Database

What it does

Fast NoSQL database for flexible data. No schema required, scales automatically.

Key Features

  • Sub-millisecond latency
  • Flexible JSON documents
  • Automatic scaling
  • Pay per request
  • Global tables for multi-region
Use Case: Mobile apps, real-time applications, IoT devices, gaming leaderboards
🔍

Elasticsearch

Search and Analytics

What it does

Full-text search and real-time analytics. Find information instantly across large datasets.

Key Features

  • Full-text search capabilities
  • Real-time analytics
  • Visualization with Kibana
  • Distributed and scalable
  • Security and access control
Use Case: Log analysis, e-commerce search, application search features
⚡

ElastiCache

In-Memory Cache

What it does

Ultra-fast in-memory cache to speed up applications. Reduces database load.

Key Features

  • Redis or Memcached
  • Microsecond latency
  • Automatic failover
  • Multi-AZ replication
  • Encryption at rest and in transit
Use Case: Session storage, real-time leaderboards, caching database queries
🌐

VPC

Virtual Private Cloud

What it does

Isolated network in AWS where you launch resources. Your private section of the AWS cloud.

Key Features

  • Custom IP address range
  • Public and private subnets
  • Security groups and NACLs
  • VPN and Direct Connect
  • Multi-AZ support
Use Case: Securing application infrastructure, isolating environments
⚖️

ELB

Elastic Load Balancer

What it does

Distribute traffic across multiple servers. Ensures no single server gets overwhelmed.

Key Features

  • Auto-scaling based on traffic
  • Health checks
  • SSL/TLS termination
  • Request routing
  • High availability
Use Case: Scaling web applications, handling traffic spikes, zero-downtime deployments
🗺️

Route 53

DNS Service

What it does

Manage domain names and route traffic to your applications. Like a phone directory for websites.

Key Features

  • Domain registration
  • DNS routing policies
  • Health checks
  • Traffic policies
  • Alias records for AWS resources
Use Case: Domain management, geo-routing, failover scenarios
🚀

CloudFront

CDN - Content Delivery

What it does

Speed up content delivery by caching at edge locations worldwide. Users get faster loads.

Key Features

  • Global edge locations (200+)
  • Low latency
  • DDoS protection
  • Cache invalidation
  • SSL/TLS support
Use Case: Website acceleration, video streaming, API acceleration
📊

CloudWatch

Monitoring & Logging

What it does

Monitor and log everything. See metrics, set alarms, and troubleshoot issues.

Key Features

  • Metrics collection
  • Log aggregation
  • Custom alarms
  • Dashboards
  • Log Insights queries
Use Case: Application monitoring, troubleshooting, performance analysis
🔬

X-Ray

Distributed Tracing

What it does

Trace requests through your entire application. See where bottlenecks are.

Key Features

  • Service map visualization
  • Request tracing
  • Performance insights
  • Error detection
  • Latency analysis
Use Case: Microservices debugging, performance optimization
📬

SNS

Notification Service

What it does

Send notifications: emails, SMS, push notifications. Alert people when something happens.

Key Features

  • Multiple delivery channels
  • Topic-based messaging
  • Fan-out pattern
  • Message filtering
  • Scalable
Use Case: Alarm notifications, application alerts, user notifications
📭

SQS

Message Queue

What it does

Queue messages for processing. Decouple applications so they work independently.

Key Features

  • Async message processing
  • Decouples applications
  • Automatic retries
  • Dead letter queues
  • FIFO and Standard queues
Use Case: Job processing, background tasks, microservices communication
